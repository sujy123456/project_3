# MoonBit Hackathon 2026-09 Project Statement

- **Project:** LedgerWeave — multi-source business ledger reconciliation and exception attribution engine
- **Repository:** https://github.com/sujy123456/project_3
- **Summary:** LedgerWeave is an offline MoonBit library and demo executable that reconciles typed order, payment, refund and adjustment records. It produces deterministic per-order balances and explainable findings for invalid input, unknown references, mismatch, over-collection, refund risk and overdue balances.
- **Direction and usage:** Data processing and reusable application infrastructure. It supports teams reviewing exports from commerce, subscription or internal settlement systems before manual follow-up.
- **Core features:** Integer-minor-unit money model; explicit reconciliation policy; input validation; cross-source matching; balance equation; severity-coded exception records; terminal report; tests and CI.
- **Originality / references / license:** Original implementation in this repository. The problem domain is informed by common reconciliation practice, not copied source code. There are no third-party runtime dependencies. Synthetic demo data is authored for this project. License: Apache-2.0.
